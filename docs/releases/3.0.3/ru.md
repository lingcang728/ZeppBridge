- Added: **Формат даты следует системному региону**. Порядок даты и 12/24-часовой формат времени берутся из регионального формата операционной системы, даже при английском интерфейсе; изменить их можно в Настройки → Отображение и язык.
- Improved: **Понятные пояснения о том, чего не хватает при официальной авторизации**. В списке тренировок, карточках устройств и питания теперь указано, что велоспорт и другие тренировки, определение устройств и записи о питании требуют подключения «Расширенных данных».
- Improved: **Распознавание новых моделей часов**. Добавлены коды моделей для Bip 6, Balance 3, Active 2 Square, Active 3 Premium, T-Rex Ultra 2, Cheetah Pro, Balance Ultra и Helio Strap Pro.
- Improved: **Описание обновления рассеивается в пепел**. При нажатии «Понятно» карточка рассыпается в пепел от угла с кнопкой, возвращая на главную страницу.
- Fixed: **Пропуски точечных измерений SpO₂**. В дни с большим числом замеров загрузка больше не останавливается после первой страницы — догружаются все оставшиеся данные.
- Fixed: **Смещение сна и пульса на один час в регионах с летним временем**. Если часы передавали часовой пояс без учёта летнего времени, недостающий час теперь восстанавливается по часовому поясу устройства; при первом запуске после обновления локальные данные будут пересчитаны в фоновом режиме.
