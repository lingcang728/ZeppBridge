- Added: **Davantage de types de séances reconnus (#143)**. Le ski de fond, le VTT, l’aviron et la pêche sont désormais reconnus automatiquement, et « Promenade de chien » peut être sélectionné manuellement ; les fichiers FIT exportés utilisent le sport correspondant. Le premier démarrage après la mise à jour retraite les données locales en arrière-plan.
- Added: **Effets visuels réglables**. Paramètres › Avancé et maintenance propose désormais « Automatique / Complets / Réduit » ; Réduit désactive le verre dépoli et les animations de morphing, et Linux utilise Réduit par défaut.
- Improved: **Les listes de séances et de sommeil se chargent au défilement**. Il fallait auparavant cliquer sur « Charger plus » en bas de la liste ; si le bouton passait inaperçu, vos enregistrements semblaient s’arrêter à un certain mois.
- Fixed: **« Signaler un problème » rejetait le rapport entier (#143)**. Une séance dont le type avait été modifié pouvait faire rejeter l’intégralité du rapport ; désormais, seule la correction non valide est écartée et le reste est envoyé normalement.
- Fixed: **Impossible de renvoyer un plan d’entraînement après une déconnexion**. Les semaines dont la réception n’a pas été confirmée sont renvoyées lors de la publication suivante, et l’état du plan permet aussi de cliquer directement sur « Renvoyer les semaines non confirmées ».
- Fixed: **Mois « en échec » impossibles à effacer dans le rattrapage**. Les mois pour lesquels le cloud n’a explicitement aucune donnée sont marqués « Vide dans le cloud », le mois en cours ne demande plus les jours à venir, et « Réessayer les mois en échec » lance immédiatement le rattrapage dès la mise en file.
- Fixed: **La connexion n’ouvrait pas le navigateur avec l’AppImage Linux**. Avant d’ouvrir le navigateur ou le dossier de données, les chemins de bibliothèques intégrés à l’AppImage sont retirés afin que le navigateur du système démarre normalement.
- Fixed: **Plantage de l’AppImage Linux sur les distributions récentes**. Sur des systèmes comme Ubuntu 26.04, elle pouvait planter en se mélangeant avec les composants multimédias du système ; elle embarque désormais les siens. Merci à @guiliznas d’avoir identifié la cause.
