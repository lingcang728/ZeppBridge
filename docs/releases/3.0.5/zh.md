- 新增：**认得更多运动（#143）**。越野滑雪、山地骑行、划船、钓鱼能自动识别，另有可手动选的「遛狗」；导出 FIT 时也按对应运动写入。升级后首次启动会在后台重新整理本地数据。
- 新增：**界面特效可调**。设置 › 高级与维护里有「自动 / 完整 / 低特效」三档，低特效关掉毛玻璃和形变动画；Linux 上默认就是低特效。
- 改进：**运动和睡眠列表滚到底自动加载**。以前要点底部「加载更多」，没看到按钮时，记录就像停在了某个月。
- 修复：**「反馈问题」整份发不出去（#143）**。改过类型的运动会让整份报告被拒；现在哪条纠正不合格只丢哪条，其余照常发出。
- 修复：**训练计划断网后没法重发**。没确认送达的周，下次发布时会一起重发；计划状态里也能直接点「重发未送达的周」。
- 修复：**补拉里消不掉的「失败」**。云端明确没有数据的月份记成「云端无」，当月不再去要还没到的日子；「重试失败项」排好队就直接开始补拉。
- 修复：**Linux AppImage 点登录不弹浏览器**。打开浏览器和数据文件夹之前，先去掉 AppImage 自带的库路径，让系统浏览器正常启动。
