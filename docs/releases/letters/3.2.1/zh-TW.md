今天下午，我的信匣突然湧進了十封信。那時我正在吃麥當勞，手機裡的 Personal Agent 瘋狂提醒，嚇得我還以為地震了。打開一看，才知道是大家熱情的回饋；當然，也有些措辭相當尖銳，看起來很急迫。於是我提著吃到一半的麥當勞回到電腦前，開始針對問題修復，幸好趕在今天結束前推出。

有位使用者跟我說，新版的運動詳細資訊頁簡直「糟透了」（看完我心情也糟透了），還問我改版前有沒有設身處地替使用者想過。好吧，我確實想過。其實大家可以在詳細資訊頁右上角自由選擇新版或舊版版面。不過我還是會試著把這件事在新版裡說明得更清楚一點，也許可以把復原按鈕放大一些。每次大幅改動 UI，都很難讓所有人滿意；連蘋果都一樣，iOS 26 剛推出時也被好幾億使用者取笑。很遺憾，我沒辦法做得比蘋果更好。

當然，重量訓練明細推出後，馬上就有使用者回報說它其實無法正常運作。我仔細排查，也試著在新版本推出修正。老實說，要修好它的難度和修正 Linux 版卡頓差不多，因為這兩者都是我平常接觸不多的領域：我幾乎不去健身房，最熟悉的是戶外運動（例如跑步、登山、騎車），用自己的資料就能把這些項目調得很好。至於室內訓練，我上一封信其實說過，要不是 Felipe Dias，我根本做不出來。謝了，老兄，也再次感謝你的付出。所以現在我只能盲人摸象地試著修。若還有哪裡不夠好，請大家繼續「轟炸」我。放心，我一週只吃一餐麥當勞（好吧，偶爾兩餐）。
