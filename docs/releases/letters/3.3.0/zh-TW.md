聽說今天是感恩節。Happy Thanksgiving to everyone celebrating today! 不管你過不過感恩節，我都想藉這個機會，謝謝每一位成為 ZeppBridge 社群一員的你。你們的支持、回饋和鼓勵對我意義重大。謝謝你們一路相伴！

自從上個版本以來，我又做了不少更新，於是一步跨進了 3.3.0。受到 Personal Agent 主動推送的啟發，我在首頁加上了「今日一問」，想讓「交給 AI」這件事少一點摩擦：ZeppBridge 會結合你當天的情況，挑出一個最值得問 AI 的問題，你直接交給 AI 分析就好。順帶一提，現在也可以設定開機啟動了。每次開機後，ZeppBridge 會自動同步 Zepp App 裡的新資料（如果有的話），讓你每天早上一起床就能看到昨晚睡得怎麼樣。

我也回應了大家對睡眠和運動列表的建議：以前整個列表太長，想找某一天很費力。新版可以像在手機相簿裡雙指捏合那樣，在年、月、日三種檢視之間切換。在電腦上，用 Ctrl + 滑鼠滾輪（Mac 上是 Command + 滾輪）或觸控板捏合就能切換。另外，運動列表現在可以多選、批次匯出 FIT 檔，匯入面板也重做了。

睡眠檢視也有了很大的最佳化。再次謝謝 Felipe Dias 老哥的幫忙，現在你可以在 ZeppBridge 裡選好昨晚的醒來感覺和睡前日記，把它們當作上下文放進給 AI 的提示詞裡，讓 AI 據此給出更準確的分析。睡眠列表也做了大幅改進：現在更清楚易懂，資訊量也豐富了許多，整個介面變得更「高效」。希望大家喜歡新版的睡眠介面。

同時，我也最佳化了概覽頁幾張卡片展開和收起的動畫，掉幀和卡頓比舊版少了（可惜還沒有完全消除），之後我還是會繼續最佳化。還有個好消息：現在可以直接在寫信頁附上診斷報告和結構樣本了。點一下「結構樣本」，就能把某一次運動直接寄給我，方便我排查。基本上，只要有想讓我最佳化的地方，點首頁右上角的「寫給作者」寫信給我就行。希望大家多提建議，有任何想加的功能都可以說；如果是會影響你日常使用的程式錯誤，就更要告訴我了！你們的回饋是我更新 ZeppBridge 最大的動力，謝謝啦。

另外，ZeppBridge 已經和 SparkyFitness 達成合作。他們下次發布新版本時，應該會把 ZeppBridge 列為支援的平台之一，和 Garmin Connect、Apple Health 並列。SparkyFitness 的作者非常厲害，合作的過程中我學到了很多，在此特別感謝他。這個 6.9k star 的 GitHub 專案非常棒：它是自架的，而且老實說，他們甚至有 iOS 和 Android 的原生 App，簡直強到不可思議。如果你之前就認識 SparkyFitness，這次合作或許能幫你把自己的資料版圖補得更完整。更新後如果發現哪裡沒接好，直接告訴我，我會再和 SparkyFitness 的作者商量怎麼改進。

祝各位冬日快樂！
