见字如晤，我是凌苍。

听说今天是感恩节，祝所有过节的朋友感恩节快乐！不管你过不过感恩节，我都想借这个机会，谢谢每一位成为 ZeppBridge 社区一员的你。你们的支持、反馈和鼓励对我意义重大。谢谢你们一路同行！

自上个版本以来，我又做了不少更新，于是一步跨进了 3.3.0。受 personal agent 主动推送的启发，我在首页加上了“今日一问”，想让“交给 AI”这件事少一点摩擦：ZeppBridge 会结合你今天的情况，挑出一个最值得问 AI 的问题，你直接交给 AI 分析就好。顺带一提，现在还可以设置开机自启动了。每次开机后，ZeppBridge 会自动同步 Zepp App 里的新数据（如果有的话），让你每天早上一醒来就能看到昨晚睡得怎么样。

我也回应了大家对睡眠和运动列表的建议：以前整个列表太长，想找某一天很费劲。新版可以像在手机相册里双指捏合那样，在年、月、日三种视图之间切换。在电脑端用 Ctrl + 鼠标滚轮（Mac 上是 Command + 滚轮）或者触控板捏合就能切换。另外，运动列表现在可以多选、批量导出 FIT 文件，导入面板也重做了。

睡眠视图也有了很大的优化。再次多谢 Felipe Dias 老哥的帮助，现在你可以在 ZeppBridge 里选好昨晚的睡醒心情和睡前日志，把它们作为上下文放进给 AI 的 prompt 里，让 AI 据此给出更准确的分析。睡眠列表也做了大幅改进：现在更清晰易懂，信息量也丰富了很多，整个界面变得更“高效”。希望大家喜欢新版的睡眠界面。

同时，我还优化了概览页几张卡片展开和收起的动画，掉帧和卡顿比旧版少了（可惜还没有完全消除），之后我会继续优化。还有个好消息：现在可以直接在写信页附上诊断报告和结构样本了。点一下“结构样本”，就能把某一次运动直接发给我，方便我排查。基本上，只要有想让我优化的地方，点首页右上角的“写给作者”给我写信就行。希望大家多提建议，有任何想加的功能都可以说；如果是影响你日常使用的 bug，就更要告诉我了！你们的反馈是我更新 ZeppBridge 最大的动力，谢谢啦。

另外，ZeppBridge 已经和 SparkyFitness 达成合作。他们下次发版时应该会把 ZeppBridge 列为支持的平台之一，和 Garmin Connect、Apple Health 并列。SparkyFitness 的作者非常厉害，合作过程中我学到了很多，在此特别感谢他。这个 6.9k star 的 GitHub 项目非常棒：它是自托管的，而且实话实说，他们甚至有 iOS 和安卓的原生 App，简直强到不可思议。如果你之前就认识 SparkyFitness，这次合作或许能帮你把自己的数据版图补得更完整。更新后如果发现哪里没对接好，直接告诉我，我会再和 SparkyFitness 的作者商量怎么改进。

祝各位冬日快乐！

—— 凌苍
