**关于云端 Personal Agent**

这段时间，我一直在体验 Muse、Hark 这样的云端个人助理。越是深入使用，我越觉得它们有可能改变我们生活的方式，就像 Coding Agent 正在改变软件开发一样。

不妨分享一下我过去两周的生活。

我将 ZeppBridge 与自己的个人网站连接，让 Hark 能够持续获取我的健康数据。每天早上起床后，我只需打开 Zepp 同步昨晚的睡眠，等刷完牙、洗完脸，Hark 便已经为我总结好了睡眠质量和身体恢复情况，并给出当天的训练建议。

跑完步回家的路上也是如此。同步一下数据，我便能收到刚刚那次长距离跑步的分析：心率是否过高，后半程有没有掉速，步频有没有明显变化。如果想进一步调整训练计划，回到电脑前，我还可以通过 ZeppBridge 的「交给 AI」，和 GPT、Claude 仔细讨论。

这些事情以前也能做到，但总需要我主动想起、主动整理数据，再主动发起一次对话。Personal Agent 帮我省去了最容易被忽略的一步：开始。

这种体验让我下定决心，将它带给 ZeppBridge 的用户。毕竟，连我自己都如此喜欢的功能，为什么不让大家也试试呢？

但我也犹豫了很久。ZeppBridge 从诞生之初便承诺以本地数据存储为核心，而允许云端助理持续读取健康数据，显然需要格外谨慎。

因此，这项功能默认关闭。只要你不主动启用，ZeppBridge 就不会通过它向外部服务推送你的数据，原有的使用方式也不会受到影响。

即使选择开启，你也需要准备自己的站点、配置可轮换的访问密钥，并与个人助理完成配对。它或许并不适合所有人，但如果你愿意尝试，我很推荐。

我越来越相信，这种能够主动关心你、理解你，并在恰当的时候提供帮助的个人助理，会成为未来生活的一部分。

**把「台前调度」带进运动详情**

这是从 3.0.0 开始就一直困扰我的问题。

我重新设计了几乎所有界面的卡片，唯独运动详情页迟迟没有动工。老用户可能还记得，它基本延续了 1.0.0 时的设计：卡片的位置和大小相对固定，缺少自由调整和组合的能力。

直到这两周，我在体验 iPadOS 27 时偶然打开了台前调度，突然有了灵感。

在我看来，台前调度最有趣的地方，在于它赋予了每个窗口独立的空间。你可以移动它、缩放它，也可以重新组织它与其他窗口之间的关系。于是我想，为什么 ZeppBridge 的卡片不能拥有同样的自由？

循着这个想法，我重新设计了整个运动详情页，尝试将台前调度的交互理念融入其中。

现在，你可以把心率、配速和跑步路线并排放在同一个界面上，逐点分析自己的运动表现；也可以在图表中选择某个时刻，在地图上查看当时所处的位置，了解身体表现与运动环境之间的关系。对于力量训练，你甚至可以将肌肉图和训练组放在一起，直观地查看每一组训练所涉及的肌群。

我希望每个人都能按照自己的习惯，组织那些自己真正关心的数据。

至于更多有趣的组合方式，就留给大家慢慢发掘吧。

**重新打磨 ZeppBridge CLI**

除了大家熟悉的「交给 AI」，ZeppBridge 其实还内置了 MCP 和 CLI，让 AI 工具能够直接访问本地数据，无需额外下载安装。

坦白说，这部分功能以前做得比较粗糙。直到最近收到 SparkyFitness 作者的邀约，我才重新认真审视它的价值。

这次主要做了两件事。

第一，让 AI 从「只能看」变成「能帮你记」。

现在，你可以让连接到 ZeppBridge 的 AI 帮你记录伤病、比赛、跑鞋和运动感受，也可以让它纠正识别有误的运动类型。比如，你只需告诉它「我昨天跑完步以后左膝有些疼」，它便能替你记下来。

考虑到让 AI 修改自己的数据或许有些令人不安，所有由 AI 写入的记录都会出现在设置中的「AI 最近的改动」里，随时可以撤回。AI 不具备删除数据的权限。如果你希望它只读取自己选中的数据，也可以开启「只给共享任务」，将访问范围限制在共享内容内，并禁用写入能力。

此外，你还可以让 AI 直接同步数据、导出文件。一键连接的工具也新增了 OpenCode、Grok Build 和 Factory。如果还有你喜欢的工具没有得到支持，欢迎写信告诉我。

第二，让 ZeppBridge 能够与其他自托管应用共享数据。

SparkyFitness 是一款开源的、自托管的健康记录应用。这次合作让我意识到，ZeppBridge 或许可以成为连接 Zepp 数据与其他健康应用的一座桥梁。

为此，我给 CLI 增加了常驻模式。你可以让它运行在家里的 NAS 或小型服务器上，供其他应用读取睡眠、心率、运动、体重等数据。

这项服务仅提供只读访问，需要密钥才能连接，密钥可以随时撤销。默认只允许本机访问，运动轨迹也默认不开放。它不会自行启动，如果你没有这方面的需求，完全可以忽略它。

目前 ZeppBridge 这边的工作已经完成，SparkyFitness 的适配还需要一些时间，暂时无法直接使用两者之间的集成。还请大家稍安勿躁。

写到这里，我又开始想，ZeppBridge 的未来会是什么样子？

或许我最擅长的，依然是回应你们的需求，解决那些细小却真实的问题，再偶尔做上一些新奇的动效，让大家在使用软件时多一点乐趣。

但我们能不能走得更远一些，做出一些今天还无法想象的事情呢？

我不知道。至少目前，我已经把许多曾经只存在于脑海中的想法做进了这个软件。剩下的，或许还需要一些时间，也需要继续听听你们的故事。

这就是 ZeppBridge 3.2.0。

或许，那就是我很向往的生活了。
