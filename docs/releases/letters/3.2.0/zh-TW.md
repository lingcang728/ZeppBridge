**關於雲端 Personal Agent**

這段時間，我一直在體驗 Muse、Hark 這樣的雲端個人助理。越是深入使用，我越覺得它們有可能改變我們生活的方式，就像 Coding Agent 正在改變軟體開發一樣。

不妨分享一下我過去兩週的生活。

我將 ZeppBridge 與自己的個人網站連線，讓 Hark 能夠持續取得我的健康資料。每天早上起床後，我只需打開 Zepp 同步昨晚的睡眠，等刷完牙、洗完臉，Hark 便已經為我總結好睡眠品質與身體恢復情況，並給出當天的訓練建議。

跑完步回家的路上也是如此。同步一下資料，我就能收到剛剛那次長距離跑步的分析：心率是否過高，後半段有沒有掉速，步頻有沒有明顯變化。如果想進一步調整訓練計畫，回到電腦前，我還可以透過 ZeppBridge 的「交給 AI」，和 GPT、Claude 仔細討論。

這些事情以前也能做到，但總需要我主動想起、主動整理資料，再主動發起一次對話。Personal Agent 幫我省去了最容易被忽略的一步：開始。

這種體驗讓我下定決心，將它帶給 ZeppBridge 的使用者。畢竟，連我自己都如此喜歡的功能，為什麼不讓大家也試試看呢？

但我也猶豫了很久。ZeppBridge 從誕生之初便承諾以本機資料儲存為核心，而允許雲端助理持續讀取健康資料，顯然需要格外謹慎。

因此，這項功能預設關閉。只要你不主動啟用，ZeppBridge 就不會透過它向外部服務推送你的資料，原有的使用方式也不會受到影響。

即使選擇開啟，你也需要準備自己的站台、設定可輪換的存取金鑰，並與個人助理完成配對。它或許並不適合所有人，但如果你願意嘗試，我很推薦。

我越來越相信，這種能夠主動關心你、理解你，並在恰當的時候提供幫助的個人助理，會成為未來生活的一部分。

**把「幕前調度」帶進運動詳細資訊**

這是從 3.0.0 開始就一直困擾我的問題。

我重新設計了幾乎所有畫面的卡片，唯獨運動詳細資訊頁遲遲沒有動工。老使用者可能還記得，它基本上延續了 1.0.0 時的設計：卡片的位置和大小相對固定，缺少自由調整與組合的能力。

直到這兩週，我在體驗 iPadOS 27 時偶然打開了幕前調度，突然有了靈感。

在我看來，幕前調度最有趣的地方，在於它賦予了每個視窗獨立的空間。你可以移動它、縮放它，也可以重新組織它與其他視窗之間的關係。於是我心想，為什麼 ZeppBridge 的卡片不能擁有同樣的自由？

循著這個想法，我重新設計了整個運動詳細資訊頁，嘗試將幕前調度的互動理念融入其中。

現在，你可以把心率、配速和跑步路線並排放在同一個畫面上，逐點分析自己的運動表現；也可以在圖表中選擇某個時刻，在地圖上查看當時所處的位置，了解身體表現與運動環境之間的關係。對於力量訓練，你甚至可以將肌肉圖和訓練組放在一起，直覺地查看每一組訓練所涉及的肌群。

我希望每個人都能按照自己的習慣，組織那些自己真正關心的資料。

至於更多有趣的組合方式，就留給大家慢慢發掘吧。

**重新打磨 ZeppBridge CLI**

除了大家熟悉的「交給 AI」，ZeppBridge 其實還內建了 MCP 和 CLI，讓 AI 工具能夠直接存取本機資料，無須額外下載安裝。

坦白說，這部分功能以前做得比較粗糙。直到最近收到 SparkyFitness 作者的邀約，我才重新認真審視它的價值。

這次主要做了兩件事。

第一，讓 AI 從「只能看」變成「能幫你記」。

現在，你可以讓連線到 ZeppBridge 的 AI 幫你記錄傷病、比賽、跑鞋和運動感受，也可以讓它更正辨識有誤的運動類型。比如，你只需告訴它「我昨天跑完步以後左膝有些疼」，它便能替你記下來。

考量到讓 AI 修改自己的資料或許有些令人不安，所有由 AI 寫入的記錄都會出現在設定中的「AI 最近的變更」裡，隨時可以復原。AI 不具備刪除資料的權限。如果你希望它只讀取自己選中的資料，也可以開啟「僅限共享任務」，將存取範圍限制在共享內容內，並停用寫入能力。

此外，你還可以讓 AI 直接同步資料、匯出檔案。一鍵連線的工具也新增了 OpenCode、Grok Build 和 Factory。如果還有你喜歡的工具沒有得到支援，歡迎寫信告訴我。

第二，讓 ZeppBridge 能夠與其他自架應用共享資料。

SparkyFitness 是一款開源的、自架的健康記錄應用。這次合作讓我意識到，ZeppBridge 或許可以成為連接 Zepp 資料與其他健康應用的一座橋樑。

為此，我給 CLI 增加了常駐模式。你可以讓它執行在家裡的 NAS 或小型伺服器上，供其他應用讀取睡眠、心率、運動、體重等資料。

這項服務僅提供唯讀存取，需要金鑰才能連線，金鑰可以隨時撤銷。預設只允許本機存取，運動軌跡也預設不開放。它不會自行啟動，如果你沒有這方面的需求，完全可以忽略它。

目前 ZeppBridge 這邊的工作已經完成，SparkyFitness 的適配還需要一些時間，暫時無法直接使用兩者之間的整合。還請大家稍安勿躁。

寫到這裡，我又開始想，ZeppBridge 的未來會是什麼樣子？

或許我最擅長的，依然是回應你們的需求，解決那些細小卻真實的問題，再偶爾做上一些新奇的動效，讓大家在使用軟體時多一點樂趣。

但我們能不能走得更遠一些，做出一些今天還無法想像的事情呢？

我不知道。至少目前，我已經把許多曾經只存在於腦海中的想法做進了這個軟體。剩下的，或許還需要一些時間，也需要繼續聽聽你們的故事。

這就是 ZeppBridge 3.2.0。

我在中國南方長大，沒怎麼看過雪。以前看過一位攝影師拍攝的日本青森，厚厚的積雪蓋住了房屋，道路兩旁是高高的雪牆。那樣的冬天，對我來說實在有些遙遠。

或許，那就是我很嚮往的生活了。
