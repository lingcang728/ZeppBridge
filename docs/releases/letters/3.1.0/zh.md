见字如晤，我是 ZeppBridge 的开发者凌苍。如你所见，这是一封信，只不过是寄到了你的电脑屏幕上。不出意外的话，以后每次更新，我都会像这样给你写一封信。

之所以这么做，是想更好地听到大家的声音。国内的朋友大多是在哔哩哔哩或小红书上认识 ZeppBridge 的，海外的朋友则多半来自 Reddit 和 GitHub。可在这些地方反馈问题，效率实在太低了。换位想一想：如果我是一个没有 GitHub 账号的普通用户，大概也懒得专门去提一个 issue。所以我一直在想，有没有更直接的办法，让大家发现问题的时候随手就能说出来？于是就有了“写信”。

从这封信开始，你可以在信的末尾直接回信，对 ZeppBridge 有什么看法、建议或者设想，都可以写下来。回信会匿名寄到我这里，每一封我都会认真读；除非你勾选了“允许匿名引用”，否则我不会公开你的原话。写的时候草稿会自动保存，断网了也不要紧，信会先存在本地，等联网后再寄出。

信匣里还有一些好玩的东西。每周你会收到一封数据来信，上一周一过完就自动寄到，里面是你上一周身体数据的小结。你还可以给未来的自己写信，寄给半年、一年或者三年后的自己。这些信我是看不到的，它们只存在你自己的电脑里，到了那一天才会送到你手上。

再说说 3.1.0 本身。没错，我又跳版本了，直接从 3.0.6 跳到了 3.1.0，因为这次的改动确实不小。最大的一块是新的“履历”页：这里有你一整年的活动日历，一天一个小方格，有点像 GitHub 的贡献热力图；你可以在这里记录伤病，在一张像达·芬奇手稿那样的人体图上点一下对应的部位就行；可以给自己的跑鞋起名字、记里程，快到该退役的时候它会提醒你；还有一面 PB 墙，5 公里、10 公里、半马、全马的最好成绩，都是直接从你本机的运动数据里算出来的；比赛也可以放进来，设好倒计时和优先级，赛后一键认领成绩。

我最喜欢的是“年轮”。你的运动史会变成一块真实的树木横截面，一年长一圈，哪一周练得多，那一圈就会微微鼓出来一些。我一直很喜欢把人比作树，年轮会安安静静地记下你跑过的每一段路、爬过的每一座山、练过的每一次，想分享的时候一键就能生成图片。

和 AI 一起训练也顺手了一些。练完推送到手表上的训练计划后，ZeppBridge 会顺便问你一句“练得怎么样”；要是觉得太难，一键就能把下次训练减量 10%，而且同一次训练只会问一回，不会追着你问。交给 AI 的提示词也可以存成任务了，改过的旧问法都会留着，随时能填回去，还能导出来分享给别人。顺带着，我也把不少交互动画重新打磨了一遍，希望用起来更生动一些。

最后是数据的进与出。现在你可以把 Strava、Apple 健康导出的数据，还有 GPX、FIT 文件导入 ZeppBridge；反过来，你在这里写下、整理的所有东西，也能一键导出成一份 JSON 带走。我希望 ZeppBridge 是一座字面意义上的“桥”：它只负责把你的数据连起来，绝不把你困在这里。你可以从任何地方把数据带进来，也可以把这里的任何数据带出去，这一切都是开放、免费、共享的。

还有好多好多更新，就留给你自己去慢慢发现吧，下一页我也把详细的改动列了出来。直到写这封信，我才意识到原来不知不觉做了这么多事。别看我说得云淡风轻，中间其实折腾了挺久，所以又拖了一个礼拜，抱歉啦。

冬天快要来了，最近出门跑步越来越冷，记得添衣保暖。

祝你身体健康，万事如意，我们下个版本再见！

—— 凌苍
