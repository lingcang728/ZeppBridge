- Added: **Perguntas frequentes (FAQ)**. Porquê passar por zeppbridge.com, porque só vês metade dos dados, se o Helio Strap funciona e o que fazer quando o Windows avisa para não executar a aplicação; a linha de autorização inclui uma ligação direta para o abrir.
- Added: **Ligar Claude, Codex e mais a partir da página de IA**. Uma pequena cápsula no topo leva-te à configuração de MCP com um clique em Definições, para que as ferramentas de IA leiam os teus dados locais diretamente, sem copiar e colar.
- Added: **Substituir treinos pela linha de comandos (#143)**. O zeppbridge-cli inclui o novo comando fit-override para substituir um treino por um .fit corrigido, desfazê-lo e listar substituições; executa-o em cada computador que usas.
- Added: **Sapatilhas escolhidas para o treino (#143)**. O ID das sapatilhas escolhidas no Zepp é guardado localmente e transmitido à IA através de MCP; o Zepp não envia nomes de sapatilhas. O primeiro arranque após a atualização reprocessa os dados locais em segundo plano.
- Added: **Cheetah Square na lista de modelos (#137)**. Podes escolhê-lo manualmente em Definições › Conta e dispositivos; o reconhecimento automático precisa de um relatório que inclua o código do modelo.
- Improved: **Dica única sobre o envio automático no Windows**. Na primeira vez que passas à IA, o cartão de recibo oferece-se para colar e enviar por ti, com o interruptor logo ali.
- Improved: **Saúde dos dados distingue respostas vazias (#143)**. Os pedidos aos quais o Zepp respondeu com uma lista vazia já não contam como em quarentena; o relatório de saúde dos dados do MCP lista-os separadamente dos pacotes que realmente não foi possível ler.
- Improved: **Verificação de atualizações na área de notificação (#143)**. O ZeppBridge volta a verificar a cada 6 horas; o registo inclui agora «já atualizado» e o motivo de cada fecho da aplicação.
- Fixed: **Histórico ignorado pela reposição (#143)**. As versões anteriores eliminavam dados antigos sem atualizar o registo de reposição, pelo que os meses apagados continuavam a contar como já obtidos; após a atualização, voltam à fila de reposição e basta clicar uma vez em «Iniciar reposição» em Definições › Arquivo e armazenamento para os recuperar.
- Fixed: **Terminar sessão no macOS (#145)**. Quando não é possível eliminar o item do porta-chaves, terminar sessão e desligar a autorização oficial são concluídos na mesma, em vez de falharem por completo.
