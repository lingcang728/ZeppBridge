- Added: **Часто задаваемые вопросы**. Почему перенаправляет через zeppbridge.com, почему видна только часть данных, работает ли Helio Strap и что делать, если Windows не советует запускать приложение; в строке авторизации есть прямая ссылка.
- Added: **Подключение Claude, Codex и др. со страницы «Передать ИИ»**. Небольшая плашка вверху позволяет в один клик настроить MCP в «Настройках», благодаря чему ИИ-инструменты читают локальные данные напрямую, без копирования и вставки.
- Added: **Замена тренировок из командной строки (#143)**. В zeppbridge-cli появилась команда fit-override, позволяющая заменить тренировку исправленным файлом .fit, отменить замену или вывести список переопределений; запустите её на каждом используемом компьютере.
- Added: **Учёт обуви, выбранной для тренировки (#143)**. ID обуви, выбранной для тренировки в Zepp, сохраняется в локальной базе и передаётся ИИ через MCP; названия обуви Zepp не передаёт. При первом запуске после обновления локальные данные будут заново обработаны в фоновом режиме.
- Added: **Cheetah Square в списке моделей (#137)**. В разделе «Настройки › Аккаунт и устройства» её можно выбрать вручную; для автоматического распознавания требуется отчёт с кодом модели.
- Improved: **Однократная подсказка об автоматической передаче в Windows**. При первой передаче данных ИИ в карточке появится подсказка с предложением вставлять и отправлять всё за вас — переключатель находится прямо в ней.
- Improved: **Диагностика данных различает пустые ответы (#143)**. Запросы, на которые Zepp ответил пустым списком, больше не считаются изолированными; отчёт MCP о целостности данных отделяет их от пакетов, которые действительно не удалось прочитать.
- Improved: **Проверка обновлений при работе в трее (#143)**. ZeppBridge повторяет проверку каждые 6 часов; в журнал теперь также записываются отметка «уже обновлено» и причина каждого выхода из приложения.
- Fixed: **Дозагрузка пропущенной истории (#143)**. Ранние версии очищали старые данные без обновления записей о дозагрузке, из-за чего удалённые месяцы считались уже загруженными; после обновления они снова возвращаются в очередь, и одно нажатие «Начать дозагрузку» в «Настройки › Архив и хранение» восстановит их.
- Fixed: **Выход из аккаунта на macOS (#145)**. Если запись в связке ключей не удаётся удалить, выход из аккаунта и отключение официальной авторизации всё равно завершаются штатно, а не приводят к сбою.
