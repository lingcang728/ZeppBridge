- Added: **로그인 시 자동 실행**. 설정 › 동기화 및 업데이트에서 켜면 컴퓨터에 로그인할 때 ZeppBridge가 자동으로 열리고 평소처럼 동기화합니다. 로그인할 때 창을 열지 않고 시스템 트레이에서만 실행되도록 설정할 수도 있습니다.
- Added: **홈 추천 카드**. 아직 돌아보지 않은 운동을 막 마쳤거나, 어젯밤 평소보다 훨씬 적게 잤거나, 며칠 동안 움직이지 않았을 때 홈 화면에 추천 카드가 표시됩니다. 한 번 누르면 관련 운동·회복 카드가 추천 카드에서 나와 홈 화면에 펼쳐집니다. 카드를 아래로 끌어 후보로 보내고, 후보 카드를 위로 끌어 패에 넣은 다음 AI에 전달할 수 있습니다. 패를 닫으면 카드들이 원래 추천 카드 안으로 돌아갑니다. 어젯밤 수면 기록이 있으면 “어젯밤 잠은 어땠을까?” 항목도 표시됩니다. 한 번에 최대 두 장이 표시되며, 닫은 유형은 그날 다시 표시되지 않습니다. 설정 › AI에서 끌 수 있습니다.
- Added: **질문별로 카드 뽑기**. AI에 데이터를 전달하는 곳에서 먼저 질문(같은 코스 비교, 같은 거리 구간의 PR, 대회 복기, 회복에 이상이 있었던 밤)을 고르면 관련 운동이나 밤을 골라 한 패로 구성합니다. 맞지 않는 카드는 후보 카드와 바꿀 수 있고, AI에 전달되는 내용도 함께 바뀝니다.
- Added: **운동·수면 목록을 앨범처럼 확대·축소**. Ctrl을 누른 채 스크롤하거나 터치패드에서 손가락을 오므려 전체 목록, 타일 그리드, 연간 히트맵 사이를 오갈 수 있습니다. 계속 오므리면 월별·연간 요약 카드로 접힙니다. 왼쪽 아래의 반투명 버튼으로도 전환할 수 있습니다. 카드나 셀을 누르면 해당 위치에서 펼쳐지고, 뒤로 돌아가면 원래 자리로 접힙니다. 운동 행에는 작은 경로 윤곽선이 표시됩니다(1km 미만은 생략). 수면 행에는 같은 시간축에 맞춘 네 줄의 수면 단계 차트가 표시됩니다.
- Improved: **더 많은 곳에서 심박수 구간 표시**. 운동 상세의 중·소형 심박수 카드가 구간별 색으로 표시되고 아래에 얇은 구간 막대가 추가됩니다. 마우스를 올리면 각 구간의 비율과 시간을 볼 수 있습니다. 운동 목록의 각 행에도 구간 막대가 표시되고, 훈련 상태 페이지에는 사용하는 구간 모델을 함께 표시하는 주간 구간별 시간 막대가 추가됩니다.
- Improved: **확인 창을 앱 안에 표시**. 삭제, 연결 해제, 로그아웃 시 시스템 대화상자 대신 앱 인터페이스에 어울리는 반투명 패널이 표시됩니다. 되돌릴 수 없는 작업은 빨간색으로 표시되며, Esc를 누르면 취소됩니다.
- Improved: **동기화는 성공했지만 데이터가 없을 때 가능한 원인을 하나 더 안내**. 시계와 연결된 계정이 아닌 다른 계정으로 로그인했을 수 있습니다. Google 또는 Apple로 가입한 계정은 먼저 Zepp App에서 이메일을 연결한 다음, 해당 이메일로 로그인하세요.
- Improved: **밝은 테마를 중립적인 웜 그레이로 변경**. 배경, 글자와 테두리에서 옅은 녹색 기운을 없애 더 깔끔해졌습니다.
- Improved: **Zepp Cloud 아이콘을 새로 그렸습니다**. 홈의 데이터 출처에 표시되는 Zepp Cloud 아이콘을 어두운 유리 구름 모양의 벡터 이미지로 바꿔 고해상도 화면에서도 선명하게 보입니다.
- Improved: **수면 단계 차트가 더 읽기 쉬워졌습니다**. 수면 단계는 깨어 있음, REM, 얕은 수면, 깊은 수면으로 구분된 네 줄에 표시됩니다. 시간축과 시작·종료 시각에는 오전과 오후가 표시되어 자정 전에 잠들고 다음 날 아침에 일어난 기록을 한눈에 파악할 수 있습니다(24시간제 설정은 그대로 적용됩니다). 수면 구간에 마우스를 올리면 해당 구간이 살짝 솟아오르며 지속 시간과 시작·종료 시각을 표시합니다. 각 단계의 지속 시간과 비율은 차트 위로 옮겨져 범례 역할도 합니다. “출처 및 기기”는 기본으로 접혀 있습니다.
- Fixed: **베타 버전에서 정식 버전으로 업데이트해도 해당 버전의 작성자 편지가 도착합니다**. 이전에는 업데이트 안내만 표시되고 편지는 이미 읽은 것으로 처리되었습니다.
- Fixed: **생활 사건 이름이 추세 그래프에서 겹치지 않습니다**. 여러 시기가 가까우면 이름을 두 줄에 나누어 배치하고 각 시기의 색 띠 위에 표시합니다. 공간이 부족해 숨겨진 이름도 해당 영역에 마우스를 올리면 확인할 수 있습니다.
