- 新增：**开机自启**。在设置 › 同步与更新里打开，登录电脑后自动启动并照常同步；还可以选开机后只留在托盘、不弹窗口。
- 新增：**首页「今日一问」**。首页只放一张卡，按你今天的情况挑一个最值得问 AI 的问题：刚比完赛就复盘这场比赛，刚刷了 PR 就问进步了没有，刚练完、昨晚恢复不对劲、睡得差、好几天没动也各有一问，平时就是「帮我排明天」。不想问这个就点左边的刷新键换一问，可以一直换。点开卡片，相关的运动和夜晚就在原地发成一手牌：「换几张牌」从候补里换，满意了直接复制给你选的 AI，或者去交给 AI 页再细调；收起时牌原路缩回卡里。不想要可以关掉今天这张，或在设置 › AI 里整个关掉。
- 新增：**运动和睡眠列表分日、月、年三档**。按住 Ctrl 滚动滚轮或在触控板上捏合就换一档，左下角的托盘也能拖着换，点开它还有选择记录、导入运动。月档每个月开头一行汇总：睡眠写平均时长、评分、入睡时间和比上个月多睡了多少，运动写次数、距离、时长；睡眠年档在热力图上方多一张年度分析，运动年档就是整页履历。睡眠每一行写时长、评分，再加入睡和起床两个点；运动行多了一个微缩轨迹（不到 1 公里的不画）。原来的「最近记录」页并进了这两个列表，列表够长时滚动条旁一直标着年份。
- 新增：**写给作者的信可以附上一次运动的结构样本**。遇到应用还读不懂的运动（比如泳池游泳的逐趟泳姿），在信纸上点「结构样本」就附上最近一次，从运动详情的来源卡点「写信给作者」就附上那一次；点开能先看完整内容再寄。样本只留字段名、结构和泳姿、池长、距离、时长这类编码，心率等健康数值换成占位值，坐标、地点、设备号和账号整个删掉，时间平移到 2000 年。
- 改进：**心率区间出现在更多地方**。运动详情里中小尺寸的心率卡也按区间着色，底下有一条区间细条，指上去能看到每段的占比和时长；训练状态页新增按周的区间时长柱，并注明用的是哪种区间模型。
- 改进：**确认框换成应用内的**。删除、断开、退出登录这类操作的确认不再弹系统对话框，改成和界面一致的毛玻璃小窗；不可逆的操作按钮标成红色，按 Esc 就是取消。
- 改进：**同步跑通却没有数据时，多提醒一种可能**。登录的也许不是手表绑定的那个账号：用 Google / Apple 注册的账号，要先在 Zepp App 里绑定邮箱，再用邮箱登录。
- 改进：**浅色主题换成中性暖灰**。底色、文字和描边去掉了原来那层灰绿，看起来更干净。
- 改进：**Zepp 云端图标重画了**。首页数据来源里的 Zepp 云端图标换成矢量画的深色玻璃云，高分屏上不再发虚。
- 改进：**睡眠阶段图更好读了**。左边按清醒、REM、浅睡、深睡分成四档，每档一条泳道；时间写成「凌晨 1:07」「早晨 9:31」这样的时段，前一晚入睡、第二天早上醒来也一眼分得清（设置里选了 24 小时制的照旧）；指到哪一段，那一段就轻轻跳一下并标出时长和起止；各阶段的时长和占比挪到图的上方，兼当图例；「来源与设备」默认折起来。
- 修复：**装过测试版的电脑升到正式版，也会收到这一版的作者来信**。以前只弹更新说明，信被当成已经读过。
- 修复：**趋势图上几段生活事件的名字不再叠在一起**。几段「纪元」挨得近时，名字分两行写在各自的色带上；实在放不下的不在图上写，悬停时照样能看到。
