- 新增：**开机自启**。在设置 › 同步与更新里打开，登录电脑后自动启动并照常同步；还可以选开机后只留在托盘、不弹窗口。
- 新增：**首页建议卡**。刚练完还没复盘、昨晚睡得明显比平时少、好几天没动的时候，首页会出一张建议卡，点一下就把相关的运动和恢复发成一手牌，直接交给 AI。最多同时两张，关掉的那类当天不再出；不想要可以在设置 › AI 里整个关掉。
- 新增：**按问题发牌**。在交给 AI 的地方先挑一个问题（同一路线比一比、同距离段的 PR、比赛复盘、恢复异常的那几晚），应用按规则挑出相关的运动或夜晚发成一手牌；不合适的牌可以从候补里换，交给 AI 的内容跟着变。
- 改进：**确认框换成应用内的**。删除、断开、退出登录这类操作的确认不再弹系统对话框，改成和界面一致的毛玻璃小窗；不可逆的操作按钮标成红色，按 Esc 就是取消。
- 改进：**同步跑通却没有数据时，多提醒一种可能**。登录的也许不是手表绑定的那个账号：用 Google / Apple 注册的账号，要先在 Zepp App 里绑定邮箱，再用邮箱登录。
- 改进：**浅色主题换成中性暖灰**。底色、文字和描边去掉了原来那层灰绿，看起来更干净。
- 改进：**应用里的品牌图标改成矢量**。Z 标和 Zepp Cloud 图标在高分屏上不再发虚。
- 修复：**装过测试版的电脑升到正式版，也会收到这一版的作者来信**。以前只弹更新说明，信被当成已经读过。
