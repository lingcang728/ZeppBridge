- 新增：**開機啟動**。在「設定 › 同步與更新」中開啟後，登入電腦時 ZeppBridge 會自動啟動並照常同步。也可以設定開機時僅留在通知區域，不顯示視窗。
- 新增：**首頁建議卡**。剛完成運動但還沒回顧、昨晚睡得明顯比平常少，或好幾天沒有運動時，首頁會顯示建議卡。點一下，相關的運動和恢復資料就會從這張卡發到首頁，攤開成一手牌。把牌往下拖進候補即可抽掉，從候補把牌往上拖即可換入，確認後再交給 AI。關閉這手牌時，牌會原路收回建議卡。若昨晚有睡眠紀錄，還會多一項「昨晚睡得如何？」。同時最多顯示兩張，關閉的建議類型當天不會再出現。也可以到設定 › AI 關閉這項功能。
- 新增：**依問題發牌**。在交付資料給 AI 時先選擇問題（比較相同路線、同距離組別的 PR、賽事回顧，或恢復狀況異常的夜晚），應用程式會依規則挑出相關運動或夜晚組成一手牌。若從候補換入其他卡片，交給 AI 的內容也會更新。
- 新增：**運動與睡眠清單可像相簿一樣縮放**。按住 Ctrl 並滾動滑鼠滾輪，或在觸控板上捏合，即可在完整清單、方塊網格與全年熱力圖之間切換。繼續捏合就會縮成按月、按年彙整的卡片，左下角的玻璃按鈕也能切換。點選卡片或格子，內容會從該處展開，返回時則收回原處。運動列現在會顯示縮小的路線輪廓（不足 1 公里的不顯示），睡眠列則會顯示對齊同一條時間軸的四列睡眠階段圖。
- 改進：**更多地方顯示心率區間**。運動詳情中的中、小尺寸心率卡也會依區間著色，卡片下方新增區間細條，游標移至細條上即可查看各區間的占比與時長。運動清單每列也會顯示區間細條，訓練狀態頁則新增每週區間時長長條圖，並標示使用的區間模型。
- 改進：**確認框改為應用程式內顯示**。刪除、中斷連線、登出等操作不再跳出系統對話框，改以與介面一致的毛玻璃小視窗呈現；不可復原的操作按鈕會標示為紅色，按 Esc 即可取消。
- 改進：**同步成功卻沒有資料時，多提醒一種可能原因**。登入的可能不是手錶綁定的那個帳號：以 Google / Apple 註冊的帳號，須先在 Zepp App 中綁定電子郵件，再以電子郵件登入。
- 改進：**淺色主題改為中性暖灰色**。背景、文字和外框去掉原有的灰綠色調，畫面看起來更清爽。
- 改進：**Zepp Cloud 圖示重新繪製**。首頁資料來源中的 Zepp Cloud 圖示改以向量繪製的深色玻璃雲呈現，在高解析度螢幕上也清晰銳利。
- 改進：**睡眠階段圖更好讀**。睡眠階段改以四列顯示，分別標示清醒、REM、淺睡和深睡。時間軸與起訖時間會標示時段，讓前一晚入睡、隔天早上醒來的紀錄一眼就能看懂（若設定為 24 小時制，則維持原設定）。游標移到哪一段，該段就會輕輕跳起，顯示持續時間與起訖時間。各階段的持續時間與占比移到圖表上方，也作為圖例。「來源與裝置」預設收起。
- 修復：**曾安裝測試版的電腦升級至正式版後，也會收到這一版的作者來信**。先前只會顯示更新說明，來信卻會被誤標為已讀。
- 修復：**趨勢圖上的生活事件名稱不再重疊**。多段紀元相近時，名稱會分成兩行，並各自顯示在所屬色帶上。無法容納的名稱不會顯示在圖表中，懸停時仍可查看。
