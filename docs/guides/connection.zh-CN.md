# ZeppBridge 连接指南

本页说明 ZeppBridge 的三种连接方式：先用的「Zepp 账号授权」、补全官方接口没有的指标的「高级数据连接」，以及最后的手动填写。

[English version](connection.md)

## 先了解三件事

- 两条登录路径都只打开 Zepp / Huami 的官方页面。请在你自己的账号里完成登录。
- token 能访问你的健康数据。不要把 token、完整请求头、抓包文件或登录截图发到公开渠道。
- 登录信息只保存在本机：token 进系统凭据存储（Windows Credential Manager / macOS 钥匙串 / Linux Secret Service），`auth.json` 只留用户 ID 和区域主机等元数据。Linux 上没有密钥环的机器另有两个选项，见 [Linux 指南](linux.zh-CN.md)。

## 推荐：用 Zepp 账号授权

这是 Zepp 官方开放平台的授权。它在你平时用的浏览器里完成，所以
**Google、小米、Facebook、Apple 登录都能用**——以前在应用内登录窗口里点了没反应的就是这几个。

1. 启动 ZeppBridge，进入「设置 → 账号与设备 → 登录方式」。
2. 在「Zepp 账号授权」那一行点「授权」，默认浏览器会打开 Zepp 自己的授权页。
3. 按你平时的方式登录，同意授权给 ZeppBridge。
4. 浏览器显示「授权成功」后回到 ZeppBridge，几秒内会自动连上；浏览器标签页可以关掉。

经过我们服务器（`zeppbridge.pages.dev`，Cloudflare）的东西和原因：Zepp 规定授权码
换成令牌这一步必须带只能放在服务器上的应用密钥，所以这一步在那里完成。令牌等待期间是
加密存放的，只交给你的 ZeppBridge 一次，被领走的同时删除，最长留 10 分钟。你的电脑用
一个从不出现在浏览器里的一次性密钥证明这次授权是它发起的。以后刷新令牌也经过同一个
服务器，由它补上应用密钥，什么都不留。详见[安全与隐私](../reference/security-and-privacy.zh-CN.md)。

令牌随后存进系统凭据存储，和高级数据连接的令牌分开存。「断开」会在 Zepp 那边撤销授权并
删掉本机令牌，**不会删除任何健康数据**。

官方授权同步哪些数据，取决于下面的高级数据有没有也连上。ZeppBridge 对每一样数据都取更丰富的那一边：

| 数据 | 只连官方授权 | 两边都连 |
|---|---|---|
| 睡眠 | 官方（含小睡、REM 真值） | 官方；高级数据里的同一晚照样保存，但不重复显示 |
| 每小时步数 | 官方 | 官方（只有官方有） |
| 心率、每日步数、带轨迹的运动、PAI、体重 | 官方 | 高级数据（字段更全：训练负荷、训练效果、最大心率、体成分） |
| HRV、血氧、压力、准备度、训练负荷 | 没有 | 高级数据 |

> HRV、血氧、压力、准备度这类指标官方接口根本没有，只能来自下面的高级数据连接。

## 高级数据：邮箱或手机号登录

这条连接读取官方接口没有的数据。它在应用内嵌的窗口里登录，而第三方登录服务会拦截这种窗口，
所以这里只能用邮箱或手机号 + 密码，**不能**用 Google、小米、Facebook、Apple 登录。

### 1. 打开连接

1. 启动 ZeppBridge，进入「设置」。
2. 在「高级数据连接」那一行点「使用」。
3. 应用会弹出独立窗口，默认打开 `https://watchface.zepp.com/`。

### 2. 在弹出窗口里登录

1. 用你的 Zepp 账号完成网页登录。
2. 应用会在登录窗口内读取会话 cookie（不会把 token 显示在界面上）。
   每次连接都使用隔离的浏览器会话，登录窗口关闭后随即丢弃。
3. 顶部状态会依次变为「等待登录 → 正在提取 → 正在验证 → 已连接」。
4. 验证通过后弹出窗口会关闭，设置页自动刷新。若本机还没有云端同步记录，会接着跑一次增量同步。

应用会优先使用登录页返回的真实区域地址，再尝试已知兜底区域；凭据被拒和区域
服务暂时无法访问会显示为不同错误。

如果主登录页开着却一直没人动——没输入、没点击，窗口也还停在应用打开的那一页——大约 90 秒后会改开备用页 `https://user.huami.com/privacy2/index.html`。这条兜底是给「页面根本没渲染出来」准备的，所以不会在你登录到一半时触发：只要你开始输入或点击，或者页面已经走到小米、Google、Facebook、微信的登录页，本次会话就不会再自动跳转，免得把正在输的密码或验证码冲掉。整次会话超过 15 分钟会超时，可点「重试连接」。

### 3. 以后怎么用

认证保存成功后，日常同步由电脑直接访问你所在区域的 Zepp 服务。关窗口会留在托盘，不必每次重新登录。只有 401/403 或设置页显示「需要重新连接」时，再点「重新连接」。

## 备用方式：手动填写

已经通过你自己控制的合法途径拿到凭据时用这条。设置页「认证方式」里选「手动输入」，填三项：

| 字段 | 说明 |
| --- | --- |
| App Token | 登录后的访问凭据 |
| User ID | 你的 Zepp 数字用户 ID |
| 区域地址 | 形如 `https://api-mifit-us3.zepp.com`，国服是 `api-mifit*.huami.com` |

区域地址只接受 `https://api-mifit*.zepp.com` 或 `https://api-mifit*.huami.com`，不能带端口、路径、查询参数、fragment 或凭据——这条限制在连接器里强制校验，填错会直接拒绝。

token 只写入系统凭据管理器，界面上永远不会显示完整 token。

**若 token 来源不明，宁可不要导入。**

## 常见故障

| 现象 | 先检查 | 仍失败时 |
| --- | --- | --- |
| 点「连接」没有弹出窗口 | 是否在桌面应用内操作；杀毒/窗口管理是否拦截新窗口 | 重启应用后再试 |
| 一直停在「等待登录」 | 是否已在弹出窗口真正登录成功 | 取消后重试，或改用上面的手动填写 |
| 提示未能验证区域 | 网络是否能访问 Zepp 区域 API；账号是否已登录完成 | 换网络或稍后重试；确认登录页属于 zepp.com / huami.com |
| 提示「正在重试连接区域服务」 | 不用管；登录窗口会留着一直重试，直到网络恢复或整场会话超时 | 修好网络，或取消后重试 |
| 提示令牌没能存进系统凭据管理器 | Windows 凭据管理器 / macOS 钥匙串 / Linux Secret Service 是否被系统策略禁用或根本没在跑 | 错误信息里带着底层原因；据此区分「被禁用」和「令牌超出容量」 |
| 登录超时 | 是否超过 15 分钟未完成 | 点「重试连接」 |
| 显示「需要重新连接」 | token 是否过期；是否刚清除认证 | 重新走网页登录 |
| 睡眠显示「未验证/不可用」 | `band_data` 可能是压缩或编码 payload | 当前只保留 raw，不伪造睡眠阶段 |
| 同步只完成一部分 | 查看设置页「高级与隐私」里的数据流状态 | 核心流失败时重试；可选流不可用不等于其他数据丢失 |

## 清除认证与本地数据

- 「清除认证」会取消进行中的网页登录、删除 Windows Credential Manager 中对应用户的 token、删除认证元数据，并重置内存中的连接状态；它**不会**删除已有健康数据库。
- 设置页可选择本地保留 1–365 天（默认 365）。成功同步后按该天数清理；手动「清理旧数据」用同一个天数，不可撤销。
- 需要完整删除时，先在设置页清除认证，再打开程序旁的 `data\` 确认；请先备份后删除整个安装文件夹。

更多边界见 [安全与隐私](../reference/security-and-privacy.zh-CN.md)。
