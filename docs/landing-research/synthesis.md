## 导航的共同职责

这批站点可以归成三种结构：多产品企业站（Product/Solutions/Resources/Pricing）、直接可用的工作台（输入/工具模式/历史/账户）和单应用下载页（能力/平台/帮助/下载）。导航的价值是帮助访客区分这些职责，并不在于区间多。大站的功能详情页负责解释一种能力，用例页解释一个受众的任务，资源页承载文档与支持，首页只承担定位、证明和下一步。

ZeppBridge 是单产品桌面工具，主页直接承担介绍与示例；连接、隐私、FAQ 和下载都用真实章节锚点。源码/技术文档是外部项目资源入口。AI 只是可选的数据交接，不把它当产品的大类或强制步骤。手机同样能去往这些章节；避免为了复制 SaaS 网站而新建空内容页。

## 字体、字重与标题

报告记录的是现场 computed CSS 样本，不是完整字体许可或视觉品牌手册。有的网站视觉标题没有语义 H1，有的自定义字体名称与 CSS weight 不一致；不能把抓到的第一个 H1 当作视觉大标题。ZeppBridge 保留本地已有 MiSans，按明确的正文、辅助、栏目和标题阶梯排版；长语种仍能换行，关键动作至少保持足够点击面积。色彩只用于品牌动作或真实指标分类，不把所有信息都做成卡片或荧光文字。

## 动效证据限制

多数报告采集初始/滚动页面、部分 hover、computed CSS、活动 Web Animations 或媒体元素。动画计数不代表质量；零动画计数不表示无事件动画/视频。它们不是完整的键盘、触屏、读屏、WCAG、Lighthouse 或设备测试。第三方站点的浏览器验证、blank canvas、骨架和商店重定向明确保留，不拿 challenge 的字体/动画归给产品。
